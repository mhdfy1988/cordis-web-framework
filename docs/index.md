# Cordis Web Framework

通过公开契约组合可信插件，开发浏览器工具、Node 服务和全栈应用。

**预发布 · 0.1.0-rc.3**　MIT，GitHub Release 交付，暂不上 npm；正式认证、生产存储与不可信插件沙箱不在当前范围。

rc.3 包含多标签页配置同步、独立插件包深色适配，以及停止当前页面后刷新保持暂停；点击“重新打开文档站”才恢复。更新范围见[更新日志](../CHANGELOG.md)。

## 从一个应用开始
