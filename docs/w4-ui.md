# W4 界面组合与可替换实现

2026-10-22：已实现；契约、真实 Chrome、工程外包消费与回归范围见文末验收记录。沿用已确认的 FluidBlock 架构第 6 节与 Harness 固定证据基线，不复制其 React 代码或业务状态。

## 边界与验收路线

无界面注册表拥有位置、候选、声明代际、等待、失败身份及只读诊断；Vue 适配拥有组件解析、错误边界、订阅和 DOM。布局插件只贡献根内容并声明子位置，功能插件贡献工作区、导航和命令；入口只装配注册服务和选定呈现器。核心不导入 Vue、路由或具体工作台。

保留四种位置：single 单项、list 按 id 分单元、keyed 按 key 分单元、chain 纯选择器链。前三种同单元同优先级冲突、数值小者覆盖；列表再按 order 排序。链按优先级与注册顺序试选，第一个非 null 结果为 matched。覆盖只作用于界面，不改变 Cordis 的显式服务绑定。

只内建 root，子位置由贡献 children 声明，重复声明拒绝。直接注册未声明位置失败；显式 inject 等待声明、随代际安装和撤销。贡献撤销递归释放子位置／贡献；停止等待不再复活。全局只可呈现 root，子位置须使用声明者受控句柄；root、session-maybe、session 作用域运行时检查，会话是编辑实例不是用户身份。

第 1 轮布局 A 声明工作区与导航，工具插件注册内容；第 2 轮撤销 A 再注册兼容布局 B，声明等待重新安装，业务会话不销毁；第 3 轮停用工具插件，命令、路由、视图、订阅一并撤销，不删除业务数据。切换时应用负责处理草稿／任务，不承诺任意热替换。

验收样例保留一个编辑会话，在侧边导航与顶部导航两种布局间切换；按钮和快捷键共用命令入口，路由与菜单分别注册。主题局限于宿主根容器变量，不修改 document 全局。测试用独立临时端口／Chrome，不替换用户已有入口，W3 原记录编辑继续回归。

## 选型与证据

- 注册表和贡献生命周期是本项目特有协议，自己掌握；JSON 结构字段沿用 Zod 运行时校验，版本用现有 semver 适配，不重写版本解释。
- Vue Router 选择 4.6.4（MIT），作为 Vue 路由适配的可选 peer／开发依赖。5.4.0 包元数据显示扩展到 Vite／Pinia 等 peer；当前不需要文件路由与数据加载器，采用最小 v4 API，后续升级独立回归。代价是一个可选依赖及动态路由同步；不在核心传播 Router 类型。
- 官方动态路由：<https://router.vuejs.org/guide/advanced/dynamic-routing.html>。addRoute 返回撤销函数，同名默认覆盖因此适配先拒绝冲突，增删后重新匹配当前 URL。
- 官方历史模式：<https://router.vuejs.org/guide/essentials/history-mode.html>。首版浏览器适配采用 hash 历史方便静态部署与深链接，memory 用于隔离实例；HTML5 history 的服务端回源配置不在此轮伪装实现。
- Vue 插槽／作用域：<https://vuejs.org/guide/components/slots.html>；组件生命周期和错误捕获复用 Vue API，不自写虚拟 DOM。
- Vue 属性透传：<https://vuejs.org/guide/components/attrs.html>；生产错误参考：<https://vuejs.org/error-reference/>。下面源码索引保留锁定版本的实际错误格式和回归落点。
- 既定来源索引：`../fluid-block/docs/harness-ui-composition-evidence.md`，固定提交 `687f282e8625c6b8d11ff58211a90524be2e4317`：ui-slots 注册／选择／递归释放，ui-renderer scoped-slots 错误隔离／声明期等待。来源只支持设计，不替代本仓验收。

## 公开入口与状态归属

| 入口（包名后的路径） | 输入 → 输出 | 退出责任 |
| --- | --- | --- |
| `/ui`、`/contracts/ui` | 位置、贡献、版本、作用域 → 受控句柄、选择结果、只读诊断 | 贡献句柄递归撤销；等待句柄停止后不复活；注册表只属于本应用 |
| `/presentation-vue/ui` | 注册表＋可信组件目录 → 通用根和受控子出口 | Vue 卸载清除订阅与组件；根不导入具体布局或业务 |
| `/commands`、`/contracts/commands` | 动作、启用条件、上下文 → 完成／禁用／缺失／忙碌／取消／失败 | 撤销命令先禁止调用并发出取消；`close()` 等真实动作结束 |
| `/presentation-vue/routing` | 路由、独立导航项、历史模式 → 当前路由和可撤销登记 | 路由撤销清除页面贡献、等待及引用导航，重新匹配当前地址；关闭历史监听 |
| `/presentation-vue/controls` | 所属容器＋命令／主题 → 撤销函数 | 快捷键只监听该容器；主题恢复原变量值及优先级，不写全局 |
| `/contracts/navigation` | 路由／导航／主题数据类型 | 不含 Vue、DOM 或 Router 类型；运行时结构由适配验证 |

位置是声明者提供的扩展出口，贡献是某插件提供的候选，单元是候选竞争的身份；会话专指编辑实例，不是登录身份。`UiHandle.children` 是本注册表验证的能力令牌，伪造数字或另一实例令牌无效。诊断记录位置和贡献标识，不展示原始异常或业务正文。

仅 `root` 可以全局读取。组件目录把 `view` 字符串映射到可信 Vue 组件；未知组件／非 Vue 呈现器算候选故障，不下载代码或假称兼容 React。组件接收 `uiContext`、`uiAccess`、`matched`；应声明所需 props，或设置 `inheritAttrs: false`，避免把协议对象透传到 DOM。布局内的子出口通过 `access` 接收能力令牌。

应用可扩充 `UiPositions` 静态声明表，用 `register` 约束位置名，用 `resolveUiPosition` 检查该位置所需输入。动态模块通过 `registerDynamic`／`resolve` 明确进入运行时路径；两条路径使用同一版本、声明和作用域校验，静态类型不是运行授权，也不验证产品 props 的完整业务 schema。

前三种位置的坏候选按编辑会话退出竞争，已登记的其他优先级候选继续竞争；没有可用候选时呈现错误，不冒充自然空白。列表中一个单元失败不吞掉其他单元。选择链的选择器异常会记录并继续，但已选组件出错只显示局部错误，不自动选下一个组件；只有显式撤销等贡献变动才重新选择。覆盖式底图在隐藏时仍保持挂载。

声明期 `inject` 的安装和撤销是**同步**协议，撤销必须幂等；异步业务和异步资源排空归插件作用域／宿主，不塞进此回调。安装错误通过 `wait-failed` 记录；撤销抛错或返回异步结果会记录 `cleanup-failed`、递增清理失败计数，并由撤销／关闭入口抛出失败供插件作用域观察，脏注册表不可继续注册或呈现，不能仅以位置数量为零宣称资源干净。安装函数在返回撤销函数之前抛错时，负责回收自己申请的外部资源。容量有上限，诊断保留最近 128 条；退出编辑实例后调用 `releaseSession` 释放相应失败标记。首版不是任意第三方代码安全沙箱。

## 命令、地址与主题规则

命令 id 和快捷键组合重复均拒绝，不随加载顺序覆盖。按钮、菜单和键盘调用 `execute`；同一命令同一会话的在途调用返回 `busy`，不同会话不互相冒充结果。启用条件异常视为不可用，动作异常返回 `failed` 并留下命令标识。登记返回的撤销函数立即禁止新调用、发送取消，再等待本命令真实在途动作结束，插件必须把它直接登记给 `scope.onDispose` 或自行 await；`close()` 同样排空全部动作。取消不强停 JavaScript，不响应取消且永不结束的动作会使排空继续等待，由既有宿主关闭预算报告超时。

快捷键只支持单个字母／数字与可选 Ctrl／⌘、Shift；不抢组合输入、重复按键、Alt 或已经处理的事件。输入框默认不匹配，保存等命令可显式 `allowInput`。没有全局键盘总线或另一套保存逻辑。

路由目前仅接受明确的字面路径，不支持参数模式、路由守卫、懒加载或权限系统。同 id、同路径在调用 Vue Router 前拒绝；大小写敏感、严格末尾斜杠匹配。路由登记通过声明期等待贡献键控页面，`key` 为路由 id；导航项单独引用已登记路由，不自动把所有路由变成菜单。hash 用于单个主地址；多个隔离实例选择 memory，不能让两个实例争同一个地址栏。移除当前路由后 `current()` 为未匹配，样例显示“页面不存在或扩展已停用”，不自动导航到旧页面。

主题仅允许 `--cw-` 前缀变量、有限长度及受限值，不能注入任意样式表或 URL。同一容器先撤销旧主题再登记新主题；保留并恢复容器原有值。两种样例主题用于验证替换，不等于已交付通用组件库、完整设计系统或无障碍认证。

## 两种布局的实际装配

`examples/ui-workspace` 复用 W3 原有 `createEditorSession`、记录表单、列表、通信及 SQLite 服务，不复制保存／权限／冲突规则。

1. 基础插件提供界面、命令和导航服务；业务插件拥有编辑会话。布局 A 提供根内容并声明相同版本的导航／内容位置；功能插件通过公开服务贡献路由、导航与保存命令。
2. 用户切换布局时，应用控制器先等待布局 A 的公开 `stop()` 真正到 `stopped`，再装载布局 B、检查 `ready`。旧 DOM／订阅销毁，声明期贡献按新代际重装；编辑会话与草稿不销毁。两布局是侧栏／顶栏两份组件，不是同一个页面改 class。
3. 帮助插件停用会撤销路由、导航和命令，重新启用使用新插件身份；不会重建记录业务会话。宿主停止则先卸载 Vue，再按依赖释放插件、导航／快捷键／主题，最后清空所属容器。

宿主 `requiredPluginIds` 可显式列出必需插件，W4 样例排除允许主动停用的帮助插件。缺省仍检查全部已装载插件，不修改运行时 `audit()` 的严格语义。宿主状态、传给资源层的缺省审计及 HTTP 就绪端点使用同一名单；可选插件的停止／失败仍在完整快照和诊断中，不被隐藏。名单格式错误在创建运行时前拒绝，不存在的必需插件在申请宿主资源前失败并收尾；初始装配仍要求整个启动组合激活成功。

初始组合仍经全量清单预检，样例替换只接受本地可信目录中的两个明确实现，不把任意外部 JSON 当作可热执行模块。主入口只装配所选插件与呈现器；业务组件不导入具体布局。通用 Root 不知道任何默认产品；样例的默认选择属于应用装配，不是框架硬编码。

查看样例：在项目根目录执行 `npm.cmd run build:ui` 后执行 `npm.cmd run example:ui`，用 Chrome 打开日志中的随机回环地址。独立数据为 `output/ui-demo/records.sqlite`，不是 W3 样例数据库。折叠的“界面插件验收”面板可切换布局、主题、帮助及停止；不把这些测试控制永久堆入业务工具栏。该身份夹具仅能用于回环本地验收，不应公开部署。
