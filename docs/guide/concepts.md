# 能力、概念与边界

## 适用范围

适合可通过可信插件装配的工具、编辑器、小型管理应用与 Node HTTP 服务。浏览器和服务端各有自己的运行时，共用契约，不共享内存服务；需要网络传输时使用显式通信。

| 状态 | 能力 |
| --- | --- |
| 已实现并有相应本地验收 | 插件预检、显式服务绑定、依赖激活与停用、诊断、配置、日志、有界关闭观察；浏览器／Node 宿主；JSON 通信；Vue 界面位置、命令、导航、主题；本地包／模板消费 |
| 受限或实验性 | Cordis `4.0.0-rc.11` 加固定补丁；记录样例的 Node 实验性 SQLite、本地身份夹具；Windows Node 24／Chrome 的当前验收，不代表所有浏览器与操作系统 |
| 未提供或未承诺 | 不可信插件沙箱、任意 URL 插件下载、完整认证／生产数据库方案、分布式调度、服务端渲染、桌面宿主、任意生产热替换、npm 正式发行 |

框架驱动的[在线文档站](https://mhdfy1988.github.io/cordis-web-framework/)已部署；本地未发布改动不自动进入在线站点或已发布附件。

默认实现可替换不等于任意时刻无损热更新。能力声明表示宿主可用性，不是可信代码的安全权限控制。

## 统一术语

框架通过 management 统一提供独立包安装、启停、卸载和意愿持久恢复，页面只是入口，见[管理教程](plugin-management.md)。原静态装配文档的 entry 仍只查询可信 Map，load 仍只是代码定义加载，不等于 install；不能把两条入口混用或把消费应用的旧 localStorage 当作框架库。支持原可信自包含 JSON 包，以及遵守框架接口的 npm 格式插件；Node 可保留多文件／普通依赖，浏览器消费预构建交付数据。仍为可信代码、同库单写，详细限制见教程。

| 术语 | 语义 |
| --- | --- |
| 公共核心 | 项目自己的运行、装配和数据契约，不暴露 Cordis 私有上下文 |
| 运行时（Runtime） | 一个应用实例内的插件、服务、状态和清理协调者 |
| 宿主（Host） | 浏览器容器或 Node HTTP 等环境接入，负责环境资源和关闭 |
| 插件定义 | `definePlugin` 的可信模块与纯配置校验；通过 `setup` 激活 |
| 服务标识 | `service<T>(id)`，跨插件契约；`T` 只提供静态类型，不校验网络数据 |
| 装配文档 | `formatVersion / plugins / bindings` 的 JSON 数据，不是 DOM 文档 |
| 模块目录（Catalog） | `entry → RegisteredPlugin` 的可信 Map，不是文件系统扫描器 |
| 插件作用域 | `get / provide / onDispose / signal`，资源随该插件释放 |
| 业务会话 | 应用拥有的编辑状态；不是用户登录，也不等于插件单例 |
| 界面位置／贡献 | 布局声明扩展出口；插件向出口登记组件候选 |
| 就绪审计 | `audit().ready`，与等待 Promise 返回分开判断 |

## 一次启动和三轮变化

启动：输入装配文档＋可信目录＋运行工厂 → 全量预检 → 创建运行时 → 提供者激活 → 消费者激活 → 就绪审计 → 宿主申请环境资源。预检拒绝时不会部分激活；激活失败则清理并给出错误快照。

第 1 轮：用户开始任务 A，应用会话登记任务身份和取消控制器。

第 2 轮：切换到 B，应用让 A 失效；A 迟到结果不能覆写 B。框架提供作用域和取消接点，不替业务决定提交条件。

第 3 轮：停止宿主，HTTP 停止接入并排空处理器，界面卸载，插件按依赖退出。超时只表示观察预算到期，未完成清理仍须负责，不能复用脏容器。已提交的数据库写入不因客户端取消自动回滚。

## 版本与所有权

包版本、插件 API、插件实现版本、服务版本和磁盘格式分别管理。当前插件 API `1.0.0`，装配格式 `1`，JSON 协议字符串 `'1'`；不是三个字段都填包版本 `0.0.0`。

应用拥有业务会话、任务、权限和持久化；插件拥有登记的资源；宿主拥有环境接入；日志与界面观察快照，不复制另一份可写运行状态。根入口不自动启动 Cordis、Vue 或 HTTP 服务。
