# 开发者手册

用公开契约组合可信插件，开发浏览器工具、Node 服务或全栈应用。框架负责装配和生命周期；业务模型、算法、账户与数据策略属于应用。

当前为 `0.1.0-rc.1` 预发布，包名 `cordis-web-framework`，自有代码采用 MIT。[GitHub Release](https://github.com/mhdfy1988/cordis-web-framework/releases) 提供交付包，暂不上 npm；不要从注册表猜装同名包。文档站使用本框架驱动的独立应用。

建议先运行 Node 模板，再完成插件教程；需要界面时转到 Vue 教程。浏览器工具可以直接选择 browser 模板，不必启动服务端。

## 文档边界

本手册描述当前接口和使用方法。[研发记录索引](../records.md)保留选型、历史阶段和验收证据，日常开发不需要依赖相邻仓库或历史聊天。所有教程示例均通过公开包导入；不需要改框架源码。

字段类型以本版本附带声明及生成签名为准，行为与资源责任见参考正文。示例真实运行与独立开发者验收分别记录：W7 核对内容和示例，W9 才做“全新目录只按文档开发应用”的整体验收，不能提前将两者等同。
