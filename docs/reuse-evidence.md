## 转移规则

逐项读取来源、复制或适配到本项目，保留必要来源说明与测试；不搬走旧文件，不复制 node_modules、output、用户数据或仓库元数据。正式包消费不能依赖相邻源码相对导入，示例和契约测试应改用本项目公开入口。

固定基线暂按来源 `cordis@4.0.0-rc.11` 加上游 PR #133 回移补丁考虑，不顺手升级；安装版本、许可、补丁守卫与可分发方式须在 W1 实际核对。已有版本适配不等于全生态插件均兼容。

通用算法和基础代码从此按新框架来源维护，应用经公开依赖使用；转移完成前保留来源回归，不能同时把两份代码都视为权威新实现。正式应用接入时再明确兼容与退出旧路径。
