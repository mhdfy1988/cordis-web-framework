# W5 纯浏览器跨应用验证

2026-10-22：W5 小型 PNG 缩放器已实现，独立包消费与真实浏览器验证见文末。本阶段不迁移 FluidBlock，也不开发完整图片处理产品。

## 最小闭环与边界

本地 PNG → 文件和尺寸预检 → 浏览器工作线程解码 → 输入目标宽度 → 等比缩放 → 透明 PNG 预览和下载。文件不上传，不需要身份、HTTP 业务接口、数据库、路由或 AI。静态资源服务器只分发文件，不参与处理。

应用来源在 `examples/png-resizer`，生产浏览器构建在工程外临时目录安装本次框架 tarball 后完成；不通过 alias 指向框架 src，不从记录样例借业务会话或样式。框架公开核心、命令、位置和 Vue 宿主保持原有协议，图片类型、尺寸规则和 Worker 均属于本应用。

| 职责 | 拥有 | 不拥有 |
| --- | --- | --- |
| 图片规则 | PNG 固定头部预检、尺寸范围、等比计算 | DOM、插件装配和完整 PNG 解码器 |
| 图片会话 | 当前已接纳源图、宽度草稿、已确认结果、任务身份和对象 URL 所有权 | Worker 事件细节、组件节点 |
| Worker 适配 | 单次线程、通信校验、超时、终止与错误映射 | 发布业务结果、全局任务队列 |
| 功能组件 | 文件输入、尺寸输入、对照预览、状态和操作意图 | 另一份可写业务状态或处理算法 |
| 应用装配 | 明确服务绑定、命令和 root 贡献、宿主启停 | 帧格式、数据库和产品专属核心分支 |

第 1 轮导入 A 后保存已接纳源图；第 2 轮处理 A 时取消或导入 B，A 的迟到结果不得覆盖 B，失败／取消保留仍有效源图和上次已确认结果；第 3 轮停止应用，终止任务并等待收尾，释放 URL、订阅、命令和节点。不同嵌入实例分别拥有自己的会话和资源。

界面采用与既有工具同类的清晰控件节奏，但不导入记录业务样式。标题与导入位于头部，源图／结果并排对照，宽度与处理／下载邻近结果；窄屏改为单列。取消只在处理中出现，不设技术参数堆叠或多级下拉。

## 选型与来源

复用现有 Vue 3、Zod 校验适配、esbuild 和 Chrome 验收，无新增第三方库。浏览器原生专用 Worker、createImageBitmap 和 OffscreenCanvas 承担图像解码／缩放／PNG 编码，避免手写编解码和把任务阻塞在主线程。不支持所需 API 时明确报错，不静默改走旧实现。

- [createImageBitmap](https://developer.mozilla.org/en-US/docs/Web/API/Window/createImageBitmap)：接收 Blob，结果是需释放的 ImageBitmap；缩放／色彩结果不承诺跨浏览器逐像素一致。
- [OffscreenCanvas.convertToBlob](https://developer.mozilla.org/en-US/docs/Web/API/OffscreenCanvas/convertToBlob)：异步 PNG 编码可失败，不能仅绘制完成就报告输出成功。
- [Worker.terminate](https://developer.mozilla.org/en-US/docs/Web/API/Worker/terminate)：立即终止，不等待线程完成操作；本应用线程没有外部写入，结果仅在主会话接纳时生效。
- [URL.revokeObjectURL](https://developer.mozilla.org/en-US/docs/Web/API/URL/revokeObjectURL_static)：不再使用时释放引用，原图和已确认结果的 URL 由会话持有到替换／关闭，不在用户点击下载后立刻回收。

只生成单张静态 PNG，输入文件上限 8 MiB，边长上限 4096、像素上限 800 万；输出同样限尺寸、PNG 上限 32 MiB。固定头部检查只用于限制资源和拒绝明显错误，完整解码由浏览器完成；动画 PNG 按浏览器解码出的首帧处理，不保留时间轴，不冒充动画支持、恶意文件安全沙箱或全格式图像库。首版没有多图、裁切或去背。

每个任务单独拥有一个专用 Worker，结束、错误、取消或 15 秒预算到期都会移除监听、清除计时并终止线程。线程回复校验版本、任务标识、未知字段、尺寸和 Blob；输出还检查 PNG 固定头部与回复尺寸，错误回复或伪 Blob 不会被显示成成功。本地任务没有外部提交；新输入和取消先改变会话代际，任何迟到结果都不能发布。关闭共享 Promise 在取消前登记，排空在途会话及命令，框架宿主继续观察真实收尾。

与记录编辑不同，图片会话不使用 JSON 通信、数据库或身份。通用处理端口归应用领域契约，Worker 适配依赖它，会话不导入具体线程实现；预览组件、输入操作组件和样式也不依赖记录样例或其私有 DOM。

## 公开使用和构建路径

应用自身入口是 `examples/png-resizer/application.ts` 的 `startImageTool({ target, workerUrl?, onError })`，返回宿主、图片会话和只读资源观察入口。`workerUrl` 缺省相对当前模块定位，嵌入时可显式传入同源静态地址；禁止跨源或非 HTTP(S) 地址。停止调用 `tool.host.stop()`，不能只移除 DOM。

在框架根目录执行：

```powershell
npm.cmd run build:png
npm.cmd run example:png
```

用 Chrome 打开第二个命令输出的随机回环地址，路径为 `/tools/png/`。构建先生成当前框架 tarball，在系统临时目录复制本应用来源和最小消费清单，使用 `--omit=dev --ignore-scripts` 显式安装 tarball 与 Vue 3.5.44，再做严格 NodeNext 和浏览器构建。最终静态文件复制到 `output/png-tool`；不从框架 src 导入，不向本项目 node_modules 塞一个框架自链接，不建立相邻项目的长期源码引用。构建工具和编译器由框架开发工具链提供，消费运行依赖不伪装成开发依赖都已安装。

`example:png` 只提供固定静态文件，没有接收上传或计算图片的 API。通过普通静态托管可运行这些文件，但本轮只验证本地等价子路径服务，**未部署到 GitHub Pages，也没有验证 file://、离线缓存或跨浏览器兼容**。

输入、输出和线程请求本身不访问业务服务器；验收的内容安全策略（CSP）设置 `connect-src 'none'`，只允许同源脚本／Worker、样式和 blob 图片。它是样例验证配置，不是对不可信插件的安全沙箱。

当前框架仍是单包：安装消费依赖时会带入 Fastify 等 Node 宿主依赖，但浏览器产物导入图证明没有打入它们；纯浏览器静态运行也不需要这些包、HTTP 客户端或 Vue Router。依赖拆包、正式模板、压缩／分块与分发策略留给 W6，不为本样例改动核心或提前改成多包工程。

## 验收与证据

单元检查尺寸边界、状态转换、取消／迟到／失败保留和资源释放。真实 Chrome 从静态子路径加载主包和 Worker，导入生成的透明 PNG，处理后下载并解码回读尺寸、颜色和 alpha；检查键盘、窄屏、取消、换图、重复挂载、双实例及停止。阻断非静态请求，证明没有后台 API。工程外只安装框架 tarball 与显式 Vue，严格类型检查、产物导入图和负例规则证明不读框架源码、不包含 Node／HTTP／记录业务或未使用路由。

本轮 130 项 Node 回归通过，包含图片规则／状态、原阶段契约及正反例边界门禁。Chrome 155.0.8059.85 从工程外消费者构建的静态文件实际执行了以下路径：

- 导入透明测试 PNG，键盘启动 320×180 → 160×90 缩放；实际下载文件并重新解码，确认尺寸、实色像素 `[40,102,166,255]` 和透明像素 alpha 为 0。
- 无效宽度不可处理；无效文件、错误任务标识及伪 PNG 回复不替换上次已确认输入／结果。不支持 Worker 的隔离环境显示明确错误，不改走另一套实现。
- 线程资源请求期间取消、处理中停止宿主；原生 Worker 与 URL API 的验收上下文跟踪确认线程和 URL 数归零，而不只相信业务自己报告的计数。
- 三轮挂载／导入／停止、两个并行实例互不影响；订阅、命令、节点与任务完成清理。空、完成、悬停、处理中、错误保留、390 像素窄屏／键盘焦点截图已实际打开检查。
- 仅允许静态资产路径，CSP 禁止业务网络连接，后台 API 路径返回 404；Worker 相对模块地址在子路径加载，无根路径硬编码。

`test:png` 可单独重做 W5；`test:package` 在同一个 tarball 候选下同时验收 W3／W4 全栈消费者和另一个全新目录的 W5 纯浏览器消费者，避免“各有一个旧包测试通过”。后者没有安装 Cordis、TypeScript 或 Vue Router；只在根工具链调用编译器，不靠祖先 node_modules 获得运行依赖。

报告为 `output/png-check-result.json` 和 `output/package-check-result.json` 的 `pureBrowser`，包含 tarball 完整性、锁文件、静态文件摘要、工程外消费目录、浏览器与回读结果。`output/png-tool/inputs.json` 保留实际导入图；`tests/png-boundaries.test.ts`／`tests/png-build.test.mjs` 的合法例与违规例验证源码／产物边界确实拦截错误。图片算法、Worker、会话及页面均只在应用目录，框架 `src` 没有产品分支；产物报告同时保留框架源码摘要。

本次可复用经验是：跨应用验证应换真实业务，并让两个应用消费同一已标识候选；静态应用既要检查导入图，也要实际加载 Worker、操作文件和回读输出。已记录到项目规则，不将本样例抽成通用图片／任务框架。W6 的模板、正式版本、发布和部署仍未开始。
