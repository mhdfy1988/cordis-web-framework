# 能力、概念与边界

## 适用范围

框架现通过统一 management 提供可信独立包的安装、启停、卸载和持久恢复；页面只是其中一种呈现入口，无页面也可管理。静态装配 entry 仍查询可信 Map，不把 load 混称 install。操作与同库单写、包格式、失败恢复等限制见[管理教程](plugin-management.md)。

适合以可信插件装配的工具、编辑器、小型管理应用与 Node HTTP 服务。浏览器和服务端各有运行时，共用契约，不共享内存服务；跨端使用显式通信。

| 状态 | 能力 |
| --- | --- |
| 已实现并有本地验收 | 插件预检、显式绑定、依赖激活与停用、诊断、配置、日志、有界关闭；浏览器／Node 宿主；JSON 通信；Vue 位置、命令、导航与主题；包与模板消费 |
| 受限或实验性 | Cordis `4.0.0-rc.11` 加固定补丁；记录样例使用 Node 实验性 SQLite 和本地身份夹具；当前 Windows／Node 24／Chrome 验收不代表全部平台 |
| 未提供或未承诺 | 不可信插件沙箱、任意 URL 插件下载、完整认证／生产数据库方案、分布式调度、服务端渲染、桌面宿主、任意生产热替换、npm 正式发行、线上文档站 |

默认实现可替换，不等于任意时刻无损热更新；宿主能力声明不等于可信代码的安全权限控制。

## 默认界面与应用界面

**框架核心不固定产品界面。** 当前另有可选的本地 `@cordis-web/default-ui` 包，提供通用布局和深浅主题，文档站已实际使用；不是安装框架后自动出现的页面。

| 层次 | 当前提供什么 | 不应理解为 |
| --- | --- | --- |
| 界面机制 | 位置声明、组件贡献、命令、导航、主题 | 自动生成侧栏、菜单、登录页或管理后台 |
| Vue 适配 | `Root`／`Outlet` 呈现接口、宿主挂载与卸载 | 成套默认布局、按钮／表单组件库或设计系统 |
| 起始模板 | 浏览器 PNG 工具、全栈记录应用、Node 服务 | 所有项目必须采用的界面和业务 |
| 当前文档应用 | 文档布局、搜索、目录、主题及复制插件 | 安装框架包就会出现的内置文档站 |
| 可选默认界面包 | 页头、导航、正文、辅助区及独立主题插件 | 完整组件库、管理后台或任意热替换管理器 |

做新应用时可以从模板修改，也可选择默认界面包，业务自行接入扩展位置。包仍为本地私有版本，未公开发行；使用方式见[界面教程](ui.md)。具体产品页面不进入公共核心。

## 统一术语

| 术语 | 含义 |
| --- | --- |
| 公共核心 | 项目自己的运行、装配和数据契约，不暴露 Cordis 私有上下文 |
| 运行时（Runtime） | 一个实例内协调插件、服务、状态和清理 |
| 宿主（Host） | 接入浏览器容器或 Node HTTP，负责环境资源与关闭 |
| 插件定义 | `definePlugin` 定义的可信模块，带纯配置校验，激活时执行 `setup` |
| 服务标识 | `service<T>(id)` 表达跨插件契约，`T` 不校验外部数据 |
| 装配文档 | `formatVersion/plugins/bindings` 数据，不是 DOM 文档 |
| 模块目录（Catalog） | `entry → RegisteredPlugin` 的可信 Map，不是文件扫描器 |
| 插件作用域 | `get/provide/onDispose/signal`，资源随插件释放 |
| 业务会话 | 应用拥有的编辑状态，不是登录或插件单例 |
| 界面位置／贡献 | 布局声明出口，插件登记组件候选 |
| 就绪审计 | `audit().ready`，不能用 Promise 返回代替 |

## 一次启动和三轮变化

### 启动顺序

装配文档与可信目录输入 → 全量预检 → 新建运行时 → 提供者与消费者按依赖激活 → 就绪审计 → 宿主申请环境资源。

预检拒绝时不部分激活；激活失败清理后给出错误快照。

### 用户操作中的状态

| 轮次 | 应用动作 | 不变式 |
| --- | --- | --- |
| 第 1 轮 | 用户开始任务 A，会话登记任务身份和取消控制器 | 任务结果属于 A |
| 第 2 轮 | 切换到 B，使 A 失效 | A 的迟到结果不能覆写 B；框架提供取消接点，不替业务决定提交 |
| 第 3 轮 | 停止宿主，HTTP 停接入并排空、卸载界面、插件按依赖退出 | 超时只是观察预算到期，不复用脏容器；已提交写入不因客户端取消回滚 |

## 版本与所有权

| 版本对象 | 当前值／约定 |
| --- | --- |
| 框架包 | `0.1.0-rc.2`，GitHub 预发布，MIT |
| 插件 API | `1.0.0` |
| 装配格式 | 数字 `1` |
| JSON 协议 | 字符串 `'1'` |
| 插件实现、服务、磁盘格式 | 各自管理，不复用框架包版本 |

应用拥有会话、任务、权限和持久化；插件拥有自己登记的资源；宿主拥有环境接入。日志和界面只观察快照，不复制第二个可写运行状态。根入口不自动启动 Cordis、Vue 或 HTTP。
