# 开发者手册

用公开契约组合可信插件，开发浏览器工具、Node 服务或全栈应用。框架负责装配和生命周期，应用负责业务模型、算法、账户与数据策略。

## 开始前确认

| 项目 | 当前状态 |
| --- | --- |
| 包名与版本 | `cordis-web-framework`，`0.1.0-rc.2` |
| 发行渠道 | MIT；GitHub 预发布附件，暂不上 npm |
| 获取方式 | 经许可取得源码或本地交付包，不安装未经确认的 npm 同名包 |
| 默认界面 | 核心不固定 UI；另有可选本地默认布局／主题包，文档站已使用 |
| 本文档站 | 框架上的独立应用，[GitHub Pages 在线阅读](https://mhdfy1988.github.io/cordis-web-framework/) |

### 选择自己的起点

- 无界面／服务端应用：先跑 Node 模板，再完成插件教程。
- 浏览器工具：直接选 browser 模板，不必启动后端。
- 全栈应用：选 fullstack，保留两端协议、权限与草稿会话边界。

## 文档边界

当前教程和参考说明使用方法，[研发记录索引](../records.md)保存选型和历史证据。日常开发不依赖相邻仓库或历史聊天，示例只通过公开包导入，不修改框架源码。

类型以交付声明与生成签名为准，副作用和清理责任见语义参考。示例实际执行、独立消费验收与正式发布是不同状态；展示代码或本地运行成功不代表已经正式上线。
